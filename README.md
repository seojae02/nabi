# Nabi

> 외국인이 한국 생활에서 마주하는 문제를 **자기 언어로** 물어보면, 공공기관 정보에 근거해 **무엇을 준비하고 어디로 가야 하는지** 알려주고, 정보만으로 부족할 때 **사람과 기관까지 연결**하는 생활 지원 서비스

**배포:** https://nabi-korea.vercel.app · 한국어 · English · Tiếng Việt · 中文

```
자기 언어로 질문 → 근거 있는 답변 → 갈 곳·준비물 안내 → 창구에서 쓰는 도구 → 안 되면 사람·기관 연결
```

---

## 1. 무엇이 문제였나

한국에 사는 외국인이 병원·부동산·행정에서 막히는 지점은 "단어를 모른다"가 아니다. **무엇을 준비해서 어디로 가야 하는지, 그리고 그 정보가 내 체류자격에 해당하는지를 판단할 수 없다**는 것이다.

| 실제 상황 | 막히는 이유 |
|---|---|
| 집주인이 보증금을 안 돌려준다 | 확정일자·내용증명이라는 절차가 있는 줄 모른다. 늦으면 돈을 잃는다 |
| 주소가 바뀌었다 | 어디에 며칠 안에 신고해야 하는지, 안 하면 어떻게 되는지 모른다 |
| 몸이 아프다 | 어느 병원인지, 건강보험이 적용되는지, 창구에서 뭐라고 말할지 모른다 |

### 기존 수단으로는 왜 안 되는가

| 수단 | 한계 |
|---|---|
| 번역기 | 문장은 바꿔주지만 **절차를 모르면 무엇을 물어볼지조차 모른다** |
| 지도 | 위치는 알려주지만 **무엇을 들고 가야 하는지**는 알려주지 않는다 |
| 범용 챗봇 | 그럴듯하게 답하지만 **출처가 없고**, "조건에 따라 다릅니다"로 끝난다. 비자·계약에서 틀린 답은 실제 피해로 이어진다 |

→ 그래서 Nabi 는 **번역기도, 지도도, 챗봇도 아닌 것**을 목표로 했다. 자세한 문제 정의는 [`docs/prd.md`](docs/prd.md) 2장.

## 2. 어떻게 풀었나 — 세 가지 원칙

이 셋 중 하나라도 빠지면 범용 챗봇과 구분되지 않는다. 그래서 셋 다 **코드로 강제**했다.

### ① 근거 — 모델의 기억으로 답하지 않는다

손으로 정제한 지식베이스(`api/_kb.js`, 카드 12장 · 출처 9곳)를 두고, 질문이 카드에 걸리면 그 내용을 시스템 프롬프트에 주입한다.

```
질문 → findCard() → 프롬프트에 근거 주입 → 답변
                 └→ 서버가 <<<SRC>>> 로 출처 링크 + 수집 시점을 붙인다
```

**출처 URL 은 모델이 만들지 않는다.** 서버가 붙인다 — 모델에 맡기면 링크를 지어낸다. 근거가 없는 카드는 만들지 않는다.

### ② 행동 가능성 — "조건에 따라 다릅니다"를 금지한다

모든 답변이 5단 구조를 따르게 시스템 프롬프트에서 강제한다.

```
① 한 문장 결론  ② 필요한 것(서류·조건)  ③ 어디서 / 어떻게  ④ 주의사항  ⑤ 출처
```

기관명·서류명은 **한국어 원문을 병기**한다. 창구에서 화면을 그대로 보여줄 수 있어야 하기 때문이다.

### ③ 연결 — 막다른 길을 만들지 않는다

정보로 안 되는 문제는 넘긴다. 진단·법적 판단·체류자격 심사 예측은 AI 가 답하지 않고 기관으로 보낸다. 그리고 **언제나 지금 당장 걸 수 있는 번호를 함께 둔다** — 비동기 요청서만 남기고 끝내지 않는다.

## 3. 어떤 기능으로 풀었나

### 물어보는 단계

| 기능 | 무엇을 해결하나 |
|---|---|
| 4개 언어 (한 · 영 · 베 · 중) | 첫 진입에서 언어 선택. AI 답변도 그 언어로 나온다 |
| 질문 먼저, 분야는 힌트 | 사용자는 자기 문제가 어느 분야인지 모른다. AI 가 판별한다 |
| 멀티턴 스트리밍 채팅 | 한 번의 Q&A 로는 안 끝난다 |
| 근거 기반 답변 + 출처 카드 | 답을 믿을 근거를 준다 |
| 후속 질문 칩 | 다음에 뭘 물어야 하는지 모르는 문제. 답변과 **같은 응답**에 실어 보내 추가 호출 없이 만든다 |
| 음성 입력 | 타이핑이 어려운 언어·상황 (Web Speech API, 서버 불필요) |

### 창구 앞에서 쓰는 단계 — 도구 3개

답을 읽는 것으로 끝나지 않는다. 실제로 막히는 곳은 **창구 앞**이다. 그래서 입력창 위에 도구를 상시 노출한다.

| 도구 | 무엇을 해결하나 | 어떻게 |
|---|---|---|
| **내 상태 한국어로** | 직원에게 설명할 말이 안 나온다 | 대화를 읽어 "저는 한국어를 잘 못합니다"로 시작하는 한국어 문장을 만든다. 화면을 그대로 내밀면 된다. **역번역을 같이 보여준다** — 자기가 무엇을 보여주는지 모르는 채로 내밀게 하지 않는다. 이름·번호 같은 식별 정보는 넣지 않는다 |
| **번역기** | 안내문·질문 한 줄을 바로 바꿔야 한다 | 양방향 · 방향 전환 · 복사. **대화 기록을 쓰지 않는다** — 번역한 문장이 다음 턴 프롬프트에 섞이면 안 되기 때문이다 |
| **시설 안내받기** | 어디로 가야 하는지 | 주민센터·출입국·보건소 등 8곳을 고르면 현재 위치 기준으로 찾는다. **대화가 가리킨 장소는 목록 맨 위에 올린다.** 좌표 조회가 막히면 네이버·카카오·구글 지도 딥링크로 넘어간다 |

### 못 풀렸을 때

| 기능 | 무엇을 해결하나 |
|---|---|
| 에스컬레이션 판정 | 근거 없음 · 금지 유형 · 3턴 이상 · 사용자 요청 → 연결 CTA 노출 |
| 연결 요청서 | **대화를 AI 가 요약해 자동 입력**한다. 처음부터 다시 설명하지 않게 한다 |
| 기관 10곳 + `tel:` 통화 | 119 · 112 · 1339 · 1345 · 132 등 **실제 번호.** 운영시간을 실시간 판정한다 |
| 응급 감지 | 키워드 감지 시 답변보다 먼저 119 / 1339 를 최상단에 띄운다 |

### 안전과 개인정보 — 지우면 안 되는 것

| 장치 | 왜 |
|---|---|
| 면책 문구를 **UI 가 강제로 붙인다** | 모델에 맡기면 빠뜨린다 |
| 응급 분기를 클라이언트 + 프롬프트 **이중**으로 | 하나가 놓쳐도 다른 쪽이 잡는다 |
| 대화 기록은 `localStorage` 에만 (최대 40개, 서버 전송 없음) | 체류자격·건강 상태는 민감정보다. 비로그인 |
| API 키는 서버리스 함수 안에만 | 저장소가 Public 이고 `index.html` 은 누구나 본다 |
| 지원자 매칭에 데모 표시 | 시드 데이터를 실제 매칭처럼 보이게 하지 않는다 |

## 4. 무엇을 얻는가

### 사용자가 얻는 것

- **한 화면에서 끝난다** — 검색 → 번역 → 지도 → 전화번호 찾기를 오갈 필요가 없다
- **믿을 근거가 있다** — 출처와 수집 시점이 붙은 답변
- **바로 행동할 수 있다** — 준비물 목록, 갈 곳, 창구에서 내밀 한국어 문장
- **막다른 길이 없다** — 정보로 안 되면 실제 번호와 사람 연결로 이어진다
- **오프라인에서도 열린다** — 데이터가 없어도 기관 목록과 119 번호는 뜬다

### 만드는 쪽이 얻는 것

- **외부 요청 0개** — 웹폰트 · 아이콘 CDN · 지도 SDK 없음. 아이콘은 인라인 SVG 스프라이트. 그래서 오프라인 기관 목록이 성립한다
- **빌드 단계 0** — `index.html` 단일 파일. `main` 에 push 하면 그대로 프로덕션
- **호출 1회 원칙** — 후속 질문·방문 장소·출처를 답변과 같은 응답에 실어 무료 티어 할당량과 지연을 늘리지 않는다
- **서버 상태 0** — DB 없음, 계정 없음. 개인정보 정책과 운영 비용이 동시에 해결된다
- **로컬 = 배포** — `scripts/dev.mjs` 가 Vercel 과 같은 코드 경로로 `api/*.js` 를 실행한다

## 5. 아직 아닌 것 — 정직하게

| 항목 | 상태 |
|---|---|
| 근거 커버리지 | ⚠️ 카드 12장. UI 예시 질문은 4개 언어 전부 덮지만 그 밖은 모델 기억에 의존한다 (PRD 목표 80%+) |
| 근거 없을 때 하드 거부 | ❌ 지금 켜면 대부분이 막힌다. 커버리지 확보 후 결정 |
| 실제 지원자 매칭 | ❌ 시드 데이터 5명. 가입·검증 플로우 없음 (기관 연결은 진짜로 동작한다) |
| 요청서 실제 전송 | ❌ 접수처가 없어 결과 화면만 보여준다 |
| NCP Maps 지역명·거리 | ⚠️ 계정 미구독으로 401. 코드는 준비됨 — 열리면 수정 없이 붙는다. 지도 딥링크는 지금도 동작 |
| 첫 응답 7~27초 | ⚠️ 모델 사고 시간. `thinkingLevel: "low"` + 인디케이터 문구로 완화 |
| 취업 · 용어 사전 | ❌ 의도적 제외 / 미구현 ([`docs/prd.md`](docs/prd.md) 5장) |

## 6. 실행하기

```bash
git clone https://github.com/seojae02/nabi.git
cd nabi
npm install                 # 실행 의존성 0개
```

루트에 `key.env` 를 만든다 (`.gitignore` 에 있어 커밋되지 않는다).

```ini
gemini_api="AIza..."        # https://aistudio.google.com/apikey
```

```bash
npm run dev                 # http://localhost:4321
```

키 발급처 · 배포 · 검증 스크립트 · 기능 추가 시 주의사항은 **[`docs/dev.md`](docs/dev.md)** 에 있다.
