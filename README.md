# Nabi

> 외국인이 한국 생활에서 마주하는 문제를 자기 언어로 물어보면, 근거 있는 정보를 쉬운 말로 설명해주고, AI만으로 부족할 때 언어 지원자나 관련 기관까지 연결해주는 생활 지원 서비스

**질문 → 근거 있는 답변 → 행동 가능한 안내 → 필요 시 사람/기관 연결**

## 왜 만드는가

한국에 거주하는 외국인은 병원·부동산·행정에서 전문적인 의사소통이 필요한 상황을 자주 만납니다. 위치를 알려주거나 문장을 번역하는 것만으로는 문제가 해결되지 않습니다.

범용 챗봇과 다른 점은 세 가지입니다.

1. **근거** — 하이코리아, 대한법률구조공단 등 실제 공공 정보에 기반하고 출처를 밝힙니다
2. **행동 가능성** — "조건에 따라 다릅니다"가 아니라 필요 서류와 갈 곳을 알려줍니다
3. **연결** — 정보로 해결되지 않는 문제는 사람과 기관으로 넘깁니다

- 한국어 / 영어 전환 (i18n 리소스 분리)
- 라이트 · 다크 테마 대응

## 실행

별도 빌드가 없습니다. 파일을 열거나 정적 서버로 띄우면 됩니다.

```bash
open index.html
# 또는
npx serve .
```

## 배포

Vercel 정적 배포입니다.

```bash
npx vercel deploy --prod --yes
```

## 핵심 분야

MVP 대상은 **의료 · 부동산 · 행정** 3개입니다. 분야는 필수 관문이 아니라 힌트이며, 사용자가 선택하지 않으면 AI가 판별합니다.

## 주의

의료·비자·계약은 잘못된 정보의 피해가 큰 영역입니다. 모든 답변에 출처와 면책 문구를 표시하며, 진단·법적 판단·체류자격 심사 예측은 AI가 직접 답하지 않고 기관 연결로 전환합니다. 자세한 정책은 [`docs/prd.md`](docs/prd.md) 6.4를 참고하세요.
