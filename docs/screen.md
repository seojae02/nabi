# Screen Spec — Nabi (Mobile App)

| 항목 | 내용 |
|---|---|
| 버전 | v1 |
| 기준 문서 | [`prd.md`](./prd.md) v2 |
| 최종 수정 | 2026-08-18 |
| 대상 | **모바일 앱 우선** (375×812 기준, 반응형 대응) |

> PRD 3장에 따라 주 사용 환경은 **현장·급한 상황·한 손 조작**이다. 모든 화면은 이 전제로 설계한다.

## 1. 화면 목록

| ID | 화면명 | 진입 경로 | MVP |
|---|---|---|---|
| `S00` | 언어 선택 (온보딩) | 최초 실행 1회 | ✅ |
| `S01` | 홈 | 앱 실행 / 탭 1 | ✅ |
| `S02` | AI 상담 (채팅) | S01 질문 입력 · 분야 카드 | ✅ |
| `S03` | 연결 요청서 | S02 CTA · S01 하단 배너 | ✅ |
| `S04` | 매칭 결과 / 기관 안내 | S03 제출 후 | ✅ |
| `S05` | 기관 목록 | S01 탭 2 · S04 더보기 | ✅ |
| `S06` | 설정 | 헤더 · 탭 3 | ✅ |
| `S07` | 용어 사전 (Bottom Sheet) | S02 용어 탭 | ⬜ Post-MVP |

## 2. 네비게이션 구조

```text
[최초 실행]
    ↓
  S00 언어 선택 ──(1회, 이후 스킵)
    ↓
┌───────────────────────────────────────┐
│              탭 바 (3탭)                │
├───────────────────────────────────────┤
│  🏠 홈        📞 기관       ⚙️ 설정      │
│  S01          S05          S06        │
└───────────────────────────────────────┘
    │
    ├─ S01 ──[질문 입력 / 분야 카드]──▶ S02 (push, 탭바 숨김)
    │           │
    │           └──[에스컬레이션 CTA]──▶ S03 (push)
    │                                     │
    │                                     └──[제출]──▶ S04 (replace)
    │                                                    │
    │                                                    └──[완료]──▶ S01 (root)
    │
    └─ S01 ──[하단 배너]───────────────▶ S03 (push, 분야 미지정 상태)
```

**규칙**
- 탭바는 S01 / S05 / S06 에서만 노출. S02~S04 는 풀스크린 push.
- S03 → S04 는 `replace`. 제출 후 뒤로가기로 요청서에 돌아가면 중복 제출 위험이 있다.
- S04 에서 뒤로가기 / 완료 → **S01 루트로 초기화**.
- S02 는 앱 재실행 시 마지막 대화를 복원하지 않는다 (PRD 11장: 세션 내에서만 유지).

## 3. 공통 요소

### 3.1 헤더

| 화면 | 좌측 | 타이틀 | 우측 |
|---|---|---|---|
| S01 | 🌏 Nabi | — | `🇺🇸 EN ▾` |
| S02 | `←` | `🏠 Housing` | `🇺🇸 EN ▾` |
| S03 | `←` | `Request Help` | — |
| S04 | `←` | `Your Request` | — |
| S05 | — | `Organizations` | `🇺🇸 EN ▾` |
| S06 | — | `Settings` | — |

- 언어 버튼은 **어느 화면에서든 2탭 이내 도달**해야 한다. 잘못된 언어로 들어온 사용자가 갇히면 안 된다.
- 언어 변경 시 현재 화면을 유지한 채 즉시 리렌더. **S02 의 기존 대화는 번역하지 않고 그대로 두되, 이후 답변부터 새 언어로 출력**한다. (과거 답변 재번역은 비용·정확성 문제)

### 3.2 하단 안전 배너 (S02 · S03 · S04)

PRD 10장 "막다른 길 없음" 원칙 구현.

```text
┌──────────────────────────────────┐
│ Need help right now?             │
│ 📞 1345 — 20 languages, free     │
└──────────────────────────────────┘
```

- `tel:1345` 링크. 항상 도달 가능.
- S02 에서는 스크롤 시 접히고, 입력창 상단에 축약형(`📞 1345`)으로 유지.

### 3.3 터치 / 타이포

| 항목 | 값 |
|---|---|
| 최소 터치 타겟 | 44 × 44 pt |
| 주요 CTA 위치 | 화면 하단 (엄지 도달 범위) |
| 본문 최소 크기 | 16 pt (외국어 가독성 확보) |
| 한국어 원문 병기 | 본문 대비 0.85배, 보조 색상 |
| 좌우 여백 | 20 pt |

### 3.4 상태 정의 (모든 목록/응답 화면 공통)

| 상태 | 처리 |
|---|---|
| Loading | 스켈레톤 (스피너 금지 — 체감 지연 큼) |
| Empty | 아이콘 + 한 문장 + 다음 행동 버튼 |
| Error | 재시도 버튼 + `📞 1345` 대안 동시 제공 |
| Offline | 상단 배너 고정. 기관 목록(S05)은 캐시로 계속 열람 가능해야 함 |

## S00 — 언어 선택 (온보딩)

### 목적
한국어를 못 읽는 사용자가 **첫 화면에서 이탈하지 않게** 한다. PRD 7장의 핵심 요구.

### 레이아웃

```text
┌──────────────────────────────────┐
│                                  │
│              🌏                  │
│                                  │
│         Choose language          │
│           언어를 선택하세요        │
│                                  │
│  ┌────────────────────────────┐  │
│  │ 🇺🇸  English            ✓  │  │ ← navigator.language 기반 기본 선택
│  └────────────────────────────┘  │
│  ┌────────────────────────────┐  │
│  │ 🇰🇷  한국어                │  │
│  └────────────────────────────┘  │
│  ┌────────────────────────────┐  │
│  │ 🇻🇳  Tiếng Việt   (soon)  │  │ ← 비활성, 40% opacity
│  └────────────────────────────┘  │
│  ┌────────────────────────────┐  │
│  │ 🇨🇳  中文          (soon)  │  │
│  └────────────────────────────┘  │
│                                  │
│  ⓘ We don't store personal data. │ ← PRD 11장 고지
│                                  │
│         [    Continue    ]       │
└──────────────────────────────────┘
```

### 동작
- 각 언어 라벨은 **해당 언어로 표기**한다 (`한국어`, `Tiếng Việt`). 영어 표기만 하면 의미가 없다.
- 국기 이모지는 보조 신호일 뿐, 텍스트 없이 국기만 쓰지 않는다.
- 선택값은 로컬 저장. 이후 실행 시 S00 스킵.
- `soon` 항목은 탭 시 토스트: "Coming soon".
- **Continue 없이 언어 탭만으로 넘어가지 않는다.** 오터치로 잘못된 언어에 갇히는 것을 방지.

### 목적
사용자가 **자기 언어로 바로 질문을 시작**하게 한다. 분야 선택은 지름길이지 관문이 아니다 (PRD 10장 원칙 1).

### 레이아웃

```text
┌──────────────────────────────────┐
│ 🌏 Nabi              🇺🇸 EN ▾    │
├──────────────────────────────────┤
│                                  │

│   with life in Korea?            │
│                                  │
│  ┌────────────────────────────┐  │
│  │ Ask anything...         🎤 │  │  ← 탭 시 S02 로 push
│  └────────────────────────────┘  │     (🎤 비활성 · Post-MVP)
│                                  │
│         [    Ask AI    ]         │  ← Primary CTA
│                                  │
│   Or choose a topic              │  ← 14pt, 보조 색상
│  ┌────────┐┌────────┐┌────────┐ │
│  │  🏥    ││  🏠    ││  🏛️   │ │
│  │Medical ││Housing ││ Admin  │ │
│  │Hospital││Contract││Visa,   │ │
│  │pharmacy││deposit ││document│ │
│  └────────┘└────────┘└────────┘ │
│                                  │
│   Common questions               │
│  ┌────────────────────────────┐  │
│  │ Can foreigners sign a      │  │  ← 탭 시 해당 질문으로 S02 진입
│  │ jeonse contract?        →  │  │
│  ├────────────────────────────┤  │
│  │ How do I report an address │  │
│  │ change?                 →  │  │
│  ├────────────────────────────┤  │
│  │ Is health insurance        │  │
│  │ available to foreigners? → │  │
│  └────────────────────────────┘  │
│                                  │
│  ─────────────────────────────   │
│  🗣️ Need to talk to a person?    │  → S03 (분야 미지정)
│     Connect with a helper    →   │
│                                  │

│   🏠 Home    📞 Orgs   ⚙️ Settings│

```

### 요소 명세

| 요소 | 동작 |
|---|---|
| 입력창 | 탭 → S02 push, 포커스 및 키보드 자동 노출. **홈에서 직접 입력받지 않는다** (전환 후 컨텍스트 유지가 단순해짐) |
| Ask AI | 분야 미지정 상태로 S02 진입. AI가 분야 판별 |
| 분야 카드 | 3개 (취업 제외 — PRD 5장). 탭 → 해당 분야로 S02 진입 |
| Common questions | 분야별 대표 질문 3개. **무엇을 물어야 할지 모르는 사용자**를 위한 진입점 |
| 하단 배너 | S03 직행. AI를 거치지 않고 바로 사람을 찾는 경로 |

### 주의
- 분야 카드에 부제(hospital, pharmacy…)를 반드시 넣는다. `Admin` 만으로는 무엇을 다루는지 외국인이 알 수 없다.
- 카드 3개는 가로 1행. 4개가 되면 2×2 그리드로 전환.

## S02 — AI 상담 (채팅)

### 목적
**멀티턴 대화**로 문제를 실제로 해결한다. PRD v1의 단발 Q&A 구조를 대체하는 화면이다.

### 레이아웃

```text
┌──────────────────────────────────┐
│ ←   🏠 Housing           🇺🇸 EN ▾│
├──────────────────────────────────┤
│                     ┌──────────┐ │
│                     │ Can I    │ │  ← 사용자 말풍선 (우측)
│                     │ sign a   │ │
│                     │ jeonse?  │ │
│                     └──────────┘ │
│                                  │
│ ┌──────────────────────────────┐ │  ← AI 답변 카드 (좌측)
│ │ ✅ Yes, foreigners can sign  │ │     ① 한 문장 결론
│ │    a jeonse contract.        │ │
│ │                              │ │
│ │ 📄 Documents you need        │ │     ② 필요한 것
│ │  · Alien Registration Card   │ │
│ │    외국인등록증          [복사]│ │     ← 한국어 원문 + 복사 버튼
│ │  · Certificate of Alien Reg. │ │
│ │    외국인등록 사실증명    [복사]│ │
│ │                              │ │
│ │ 📍 Where to go               │ │     ③ 어디서 / 어떻게
│ │  · Gov24 (정부24) online     │ │
│ │  · Immigration Office        │ │
│ │                              │ │
│ │ ⚠️ Important                 │ │     ④ 주의사항
│ │  Get 확정일자 within 14 days │ │
│ │  or you may lose your deposit│ │
│ │                              │ │
│ │ 📎 Korea Legal Aid Corp.  →  │ │     ⑤ 출처 (외부 링크)
│ │ ⓘ For reference only. Confirm│ │     면책 (고정)
│ │   with the office.           │ │
│ └──────────────────────────────┘ │
│                                  │
│  [ Where do I get this? ]        │  ← 후속 질문 제안 칩
│  [ What is 확정일자? ]            │     (가로 스크롤)
│  [ How much is the deposit? ]    │
│                                  │
├──────────────────────────────────┤
│ 🗣️ Still need help? Talk to a    │  ← 에스컬레이션 CTA
│    person  →                     │     (조건 충족 시에만)
├──────────────────────────────────┤

│ │ Type your question...    │  ↑  │
│ └──────────────────────────┘     │
└──────────────────────────────────┘
```

### 답변 카드 구조 (PRD 6.3 준수)

| 섹션 | 아이콘 | 필수 | 비고 |
|---|---|---|---|
| ① 결론 | ✅ / ❌ / ⚠️ | 필수 | 한 문장. 굵게 |
| ② 필요한 것 | 📄 | 조건부 | 서류·준비물 있을 때 |
| ③ 어디서/어떻게 | 📍 | 조건부 | 기관·온라인 경로 |
| ④ 주의사항 | ⚠️ | 조건부 | **피해 가능성이 있으면 반드시** |
| ⑤ 출처 | 📎 | **필수** | 없으면 "확인 필요" 답변으로 대체 |
| 면책 | ⓘ | **필수** | 전 답변 고정 |

### 한국어 원문 병기 (PRD 7장)

```text
Certificate of Alien Registration
외국인등록 사실증명              [복사]
```

- 기관명 · 서류명 · 주소에 적용.
- **[복사] 버튼 필수.** 창구 직원에게 화면을 보여주거나 붙여넣을 수 있어야 한다. 이게 이 서비스의 실전 가치다.
- 길게 누르면 확대 표시 (창구에서 보여주기 용도).

### 후속 질문 제안 칩

- 답변마다 2~3개 생성. 가로 스크롤.
- **무엇을 물어야 할지 모르는 사용자를 위한 장치**이자 전문 용어 학습 경로.
- 답변에 등장한 한국어 용어를 1개 이상 포함시킨다 (`What is 확정일자?`).

### 에스컬레이션 CTA

PRD 6.5 조건 충족 시에만 노출. **평소에는 숨긴다** (항상 보이면 AI가 무능하다는 신호가 된다).

| 조건 | CTA 문구 |
|---|---|
| 근거 미발견 | `We couldn't verify this. Talk to an expert →` |
| 금지 유형 (의료·법률 판단) | `This needs a professional. See organizations →` |
| 3턴 이상 지속 | `Still need help? Talk to a person →` |
| 사용자 직접 요청 | 즉시 S03 |
| 대면 절차 포함 | `Need someone with you? Find a helper →` |

### 응급 처리 (PRD 6.4)

응급 키워드 감지 시 **답변보다 먼저** 최상단에 고정 노출:

```text
┌──────────────────────────────────┐
│ 🚨 This may be an emergency      │
│                                  │
│    [ 📞 Call 119 ]               │  ← 빨강, 최상단, 스크롤 고정
│    [ 📞 1339 Medical Info ]      │
└──────────────────────────────────┘
```

### 상태

| 상태 | 처리 |
|---|---|
| 답변 생성 중 | 좌측 말풍선에 타이핑 인디케이터. 스트리밍 출력 |
| 네트워크 실패 | 말풍선 자리에 재시도 버튼 + `📞 1345` |
| 분야 미지정 진입 | 헤더 타이틀 `💬 Ask Nabi`, 첫 답변 후 판별된 분야로 헤더 교체 |
| 빈 대화 (분야 카드 진입) | 해당 분야 예시 질문 3개를 칩으로 선노출 |

## S03 — 연결 요청서

### 목적
대화 맥락을 그대로 넘겨 **사용자가 처음부터 다시 설명하지 않게** 한다.

### 레이아웃

```text
┌──────────────────────────────────┐
│ ←   Request Help                 │
├──────────────────────────────────┤
│  We'll share this with a helper. │
│                                  │
│  Language you need               │
│  ┌────────────────────────────┐  │
│  │ 🇻🇳 Tiếng Việt          ▾ │  │  ← 앱 언어와 별개 (중요)
│  └────────────────────────────┘  │
│                                  │
│  Topic                           │
│  ┌────────────────────────────┐  │
│  │ 🏠 Housing              ▾ │  │  ← S02 분야 자동 채움
│  └────────────────────────────┘  │
│                                  │
│  What you need help with         │
│  ┌────────────────────────────┐  │
│  │ Understanding a jeonse     │  │  ← AI 자동 요약 (편집 가능)
│  │ contract before signing.   │  │
│  │ Need someone present at    │  │
│  │ the contract meeting.      │  │
│  │                     ✏️ Edit │  │
│  └────────────────────────────┘  │
│                                  │
│  When                            │
│  [Weekday] [Weekend] [Anytime]   │  ← 단일 선택 칩
│                                  │
│  How to reach you                │
│  ┌────────────────────────────┐  │
│  │ Email or phone             │  │
│  └────────────────────────────┘  │
│  ⓘ Used only for this request,   │
│    then deleted.                 │  ← PRD 11장
│                                  │
│         [   Send Request   ]     │

│  Need help right now?            │
│  📞 1345 — 20 languages, free    │
└──────────────────────────────────┘
```

### 핵심 설계 판단

**"필요한 도움"을 사용자가 빈칸에서 쓰게 하지 않는다.** AI가 S02 대화에서 요약해 미리 채우고, 사용자는 확인·수정만 한다.

> 언어 장벽이 있는 사용자에게 자유 서술 입력을 요구하는 것은 서비스 전제와 모순된다.

### 필드 명세

| 필드 | 기본값 | 필수 | 비고 |
|---|---|---|---|
| Language you need | 앱 언어 | ✅ | **앱 UI 언어와 분리.** 영어 UI를 쓰지만 베트남어 통역이 필요할 수 있다 |
| Topic | S02 분야 | ✅ | S01 배너 진입 시 미선택 |
| What you need help with | AI 요약 | ✅ | 편집 가능. S01 진입 시 빈 상태 + 플레이스홀더 |
| When | Anytime | ⬜ | |
| How to reach you | — | ✅ | 이메일 또는 전화. 형식 검증 |

### 검증 / 예외
- 필수 미입력 시 해당 필드에 인라인 에러. 상단 스크롤 이동.
- 제출 실패 시 **입력값을 잃지 않는다.** 재시도 버튼 + `📞 1345`.
- 제출 버튼은 중복 탭 방지 (제출 즉시 비활성).

## 4. 접근성

| 항목 | 요구사항 |
|---|---|
| 대비 | 본문 4.5:1 이상. 한국어 병기 텍스트도 3:1 이상 유지 |
| 폰트 스케일 | 시스템 크기 200%까지 레이아웃 붕괴 없음 |
| 스크린리더 | 국기 이모지에 언어명 `aria-label` 필수 |
| 색 단독 의존 금지 | `● Open` / `○ Closed` 는 색 + 기호 + 텍스트 3중 표기 |
| 응급 배너 | 스크린리더에서 최우선 읽기 (`role="alert"`) |

## 5. 구현 우선순위

| 순서 | 범위 | 산출물 |
|---|---|---|
| 1 | S00 + S01 + i18n 구조 | 언어 전환이 실제로 동작하는 껍데기 |
| 2 | S02 채팅 + 스트리밍 | 멀티턴 대화 |
| 3 | RAG + 답변 구조화 + 출처 | **차별점의 핵심.** 여기가 데모의 승부처 |
| 4 | S05 기관 목록 + `tel:` | 실제로 동작하는 유일한 연결 기능 |
| 5 | S03 + S04 | AI 요약 자동 채움 포함 |
| 6 | S06 · 응급 처리 · 접근성 | 마감 |

> 3번(RAG + 출처)이 4~5번보다 우선이다. 연결 화면은 목업이지만 답변 품질은 목업이 불가능하다.
