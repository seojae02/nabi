### 언어

**[변경]** 계획서는 국기 이모지(`🇺🇸`)를 썼다. 실제로는 **코드 칩**(`EN` `KO` `VI` `ZH`)이다.

이유가 둘이다. `🇺🇸`가 English를 뜻하지 않고(영어권은 미국만이 아니다), 국기 이모지는 일부 안드로이드에서 두 글자로 깨진다. 언어명은 그 언어로 표기한다(`한국어`, `Tiếng Việt`).

- `en` `ko` 사용 가능 / `vi` `zh` 는 `ready:false` → 탭하면 토스트
- 어느 화면에서든 2탭 이내 도달
- 전환 시 화면 유지하고 즉시 리렌더. 채팅의 기존 답변은 재번역하지 않는다

### 아이콘

이모지를 쓰지 않는다 — 플랫폼마다 다르게 렌더링된다. `<svg class="sprite">` 안의 `<symbol>` 로 관리한다.

```
규격: 24×24 viewBox · stroke 1.6 · currentColor · 둥근 끝단
```

|---|---|
| `i-nabi` | 브랜드 마크 (채색 도형, 좌우 날개 청·황) |
| `i-cross` `i-home-door` `i-bank` | 의료 · 부동산 · 행정 |
| `i-people` `i-person` | 지원자 연결 · 지원자 카드 |
| `i-phone` `i-siren` | 통화 · 응급 |
| `i-pin` | 위치 |
| `i-clock` `i-trash` | 기록 · 삭제 |
| `i-globe` `i-gear` `i-house` | 언어 · 설정 · 홈 |
| `i-mic` `i-send` `i-sparkle` | 음성 · 전송 · AI |
| `i-arrow` `i-back` `i-caret` `i-check` `i-close` | 방향 · 상태 |
| `i-info` `i-alert` | 안내 · 경고 |

### 색 (단청 丹靑)

| 토큰 | 역할 |
|---|---|
| `--guide` | 청(靑). 주색 · CTA · 의료 |
| `--wing` / `--wing-ink` | 황(黃). 로고·장식 / **글자용**(명암비 확보) |
| `--iris` | 남(藍). 행정 · 위치 |
| `--alert` | 적(赤). **응급 전용** |

`--wing` 단색은 흰 배경에서 2.16:1 이라 글자에 쓰지 않는다. 로고와 그라디언트 장식 전용.

**시그니처** — 청→황 그라디언트를 세 곳에만 반복한다: 상단 4px 띠 / 섹션 라벨 앞 대시 / 활성 탭 표시.

### 서체

| 역할 | 처리 |
|---|---|
| 디스플레이 | weight 900 · 자간 -0.035em |
| 본문 | 시스템 산세리프 |
| 숫자 | **등폭 + `tabular-nums`** — 전화번호·운영시간·언어코드 |

웹폰트를 쓰지 않는다. 외부 요청 0개와 오프라인 동작을 지키기 위한 것이다.

### 상태 처리

| 상태 | 처리 |
|---|---|
| 로딩 | 타이핑 인디케이터 + 문구(`Nabi가 생각하고 있습니다...`). 응답이 7초 이상 걸린다 |

## S00 · 언어 선택

첫 방문에만 뜬다. 한국어를 못 읽는 사용자가 첫 화면에서 이탈하지 않게 하는 장치다.

```
        🦋 (나비 마크, 62px)
   Choose language
   언어를 선택하세요

  [ EN ] English            ✓
  [ KO ] 한국어
  [ VI ] Tiếng Việt   준비 중
  [ ZH ] 中文          준비 중

  ⓘ 대화는 이 기기에만 남습니다

     [    계속하기    ]
```

- `navigator.language` 로 기본값 추정
- **고르는 즉시 화면 언어가 바뀐다** (미리보기). 저장은 `계속하기` 를 눌렀을 때
- 오터치로 잘못된 언어에 갇히지 않도록 확정 버튼을 둔다

### 분야 선택은 화면을 옮기지 않는다

**[변경]** 계획서는 분야 카드를 누르면 채팅으로 이동했다. 실제로는 **테마만 바꾼다.**

카드를 누르면 세 곳이 동시에 바뀐다.

1. 질문 카드에 분야 배지 생성 (`⊗` 로 해제)
2. 입력창 예시가 그 분야 질문으로
3. 아래 질문 목록 전체가 그 분야로

같은 카드를 다시 누르면 해제되고 `auto` 가 된다. **선택은 선택사항이다** — 미선택이면 AI가 질문에서 분야를 판별한다.

분야마다 색이 다르다(의료=청, 부동산=황, 행정=남). 장식이 아니라 식별 정보다.

### 입력창과 버튼

**[변경]** 초기 구현은 입력창과 버튼이 **둘 다** 채팅으로 넘어갔다(중복). 지금은 역할이 나뉜다.

- 입력창: 실제로 입력받는다. `Enter` 전송, `Shift+Enter` 줄바꿈, 최대 120px 자동 확장
- `AI에게 묻기`: 그 내용을 보낸다
- 빈 칸이면 흔들림 + 토스트, 전송 차단
- 질문 목록 항목: **1탭으로 질문까지 들고 채팅 진입** (가장 빠른 경로)

```
                    └──────────┘

│ · 외국인등록증 (Alien Reg. Card)│
│ ## 주의                        │
│ 14일 내 확정일자 필요            │
│ ── ⓘ 참고용 정보입니다 ──       │ ← UI 가 강제로 붙인다
└───────────────────────────────┘
[📍 내 주변에서 찾기]              ← 방문이 필요한 답변일 때
(확정일자는?) (주민센터는 어디?)     ← 답변 기반 후속 질문
─────────────────────────────────
🗣 해결이 안 되나요? 사람과 이야기 →  ← 조건부
─────────────────────────────────
[ 질문을 입력하세요... ] 🎙  ↑
🗣 지원자 연결 │ 📞 지금 필요하면 1345
```

### 답변 렌더링

- 스트리밍. 최소 마크다운(제목·목록·강조·코드)만 지원. **이스케이프 후 변환**하므로 XSS 없음
- **면책은 모델에게 맡기지 않는다.** `addAi().finish()` 가 모든 답변에 붙인다 — 프롬프트로 요청하면 빠뜨린다
- 기관명·서류명은 한국어 원문 병기

### 제어 블록

답변과 같은 응답에 후속 질문과 장소가 실려 온다. 추가 호출이 없으므로 지연도 무료 할당량도 늘지 않는다.

```
답변...
<<<PLACE>>>
주민센터
<<<NEXT>>>
확정일자는 어떻게 받나요?
```

스트리밍 중 마커가 조각(`<<<PLA`)으로 도착하므로 꼬리를 잘라내 화면에 새지 않게 한다. 히스토리에는 제어 블록을 저장하지 않는다.

### 응급 (PRD 6.4)

클라이언트 키워드와 시스템 프롬프트가 **이중으로** 처리한다. 감지되면 답변보다 먼저 빨간 배너가 올라간다.

```
🚨 응급 상황일 수 있습니다
   구급차는 무료이며 보험이 없어도 됩니다
   [ 📞 119 전화 ]  [ 📞 1339 ]
```

### 오류

| 종류 | 문구 |
|---|---|
| `missing_api_key` | AI 가 아직 연결되지 않았습니다 |
| `rate_limited` | 무료 사용량을 모두 썼습니다 |
| `overloaded` | AI 가 지금 혼잡합니다 |
| `blocked` | AI 가 이 질문에는 답하지 않았습니다 |

모두 **재시도 + `1345` 통화**를 함께 준다. 막다른 길을 만들지 않는다.

### 에스컬레이션 (PRD 6.5)

두 경로를 나눠 뒀다.

- **상시**: 컴포저 아래 `🗣 지원자 연결` (작게)
- **조건부**: 초록 배너 — 3턴 이상 · 오류 · "사람/통역" 언급 시

크게 항상 띄우면 "AI가 못 푼다"는 신호가 되므로 나눴다.

### 음성 입력

**[변경]** 계획서는 Post-MVP 였다. Web Speech API 로 구현 — 서버도 키도 필요 없다.

- 인식 언어가 UI 언어를 따라간다 (`ko-KR` / `en-US`)
- 녹음 중 빨간 깜빡임, 다시 누르면 정지
- **기존 입력을 덮어쓰지 않고 뒤에 이어붙인다**
- 미지원 브라우저 · 권한 거부 각각 다른 안내

### 위치 추천

**[변경]** 계획서에 없던 기능이다.

`<<<PLACE>>>` 가 오면 `📍 내 주변에서 찾기` 가 붙는다. **위치는 그 버튼을 누른 순간에만 요청한다** — 진입 시에 묻지 않는다.

```
📍 서울특별시 강남구 역삼동 기준       ← NCP 권한 있을 때만
┌──────────────────────────────┐
│ 📍 역삼동 주민센터              │
│    340m 거리 · 도로명주소       │
│ [📍Naver] [📍Kakao] [📍Google]│
└──────────────────────────────┘
```

지도 제공자를 셋 다 주는 이유는 **외국인 다수가 구글 지도를 쓴다**는 것이다. 세 링크 모두 키가 필요 없고, 네이버·구글은 좌표를 실어 내 위치 중심으로 열린다.

NCP 권한이 없으면 지역명·거리 없이 검색 카드 하나만 나온다(기능은 유지).

## S03 · 연결 요청서

```
←   🗣 연결 요청서
─────────────────────────────────
ⓘ 지원자에게 전달됩니다. 신분증·카드
  번호는 적지 마세요.

필요한 언어      [ 한국어        ▾ ]
  ⓘ 앱 표시 언어와 다르게 고를 수 있습니다
분야            [ 행정          ▾ ]
필요한 도움
┌─────────────────────────────┐
│ 외국인등록증을 재발급받기 위해   │ ← AI 자동 입력
│ 출입국·외국인청에 가려고 합니다. │
│ 한국어가 서툴러 창구에서...      │
└─────────────────────────────┘
[ ✦ 대화 내용으로 채우기 ]
가능한 시간   [평일][주말][아무때나]
연락 방법    [ name@example.com  ]
  ⓘ 이 요청 처리에만 사용하고 파기합니다

     [   요청 보내기   ]
─────────────────────────────────
📞 지금 도움이 필요하면 1345
```

### 자유 서술을 요구하지 않는다

**채팅에서 넘어오면 버튼을 누르지 않아도 자동으로 채운다.** 언어 장벽이 있는 사용자에게 빈칸을 주고 설명하라고 하는 것은 서비스 전제와 모순이다(PRD 8.3).

- 대화 2턴 이상 + 칸이 비어 있을 때만 실행
- 채우는 동안 칸을 잠그고 `대화 내용을 정리하는 중...` 표시
- **자동 채우기가 실패해도 토스트를 띄우지 않는다** — 부르지도 않은 기능의 실패를 알리는 건 소음이다
- 이미 쓴 내용은 덮어쓰지 않는다

### 검증

| 필드 | 규칙 |
|---|---|
| 필요한 언어 | 필수. **앱 언어와 분리** (영어 UI + 베트남어 통역 조합이 흔하다) |
| 분야 | 채팅/홈 선택값 자동 |
| 필요한 도움 | 필수 |
| 연락 방법 | 필수. 이메일 또는 전화번호 형식 검증 |

실패 시 인라인 오류 + 해당 필드로 스크롤·포커스. 입력하면 즉시 해제.

### 필터는 예외 없이 적용된다

**[변경]** 계획서는 "응급은 필터와 무관하게 항상 최상단"이었다. 구현했더니 **필터를 눌러도 응급이 남아 필터가 고장난 것처럼 보였다.** 상시 고정을 없애고 일반 필터 항목으로 되돌렸다.

`의료` 를 누르면 의료만 남는다. 응급 접근성은 채팅 쪽에서 보장한다(응급 배너 + 상시 `1345`).

### 기관 데이터

10곳. **확인된 번호만 넣는다.** 추측한 번호는 넣지 않는다.

```
응급     119 · 112 · 1339
비자·서류 1345 · 1330 · 120 · 1588-2188
주거·법률 132 · 1566-9009
건강     1577-1000
```

- 운영시간은 기기 시각 기준 실시간 판정 → `● 운영 중` / `○ 09:00 재개`
- 데이터가 인라인이라 **오프라인에서도 열린다**
- 번호는 등폭 서체로 자리수를 맞춘다

## S06 · 대화 기록

**[변경]** 계획서에 없던 화면이다.

```
🕐 대화 기록
─────────────────────────────────
ⓘ 이 기기에만 저장됩니다. 언제든 삭제
  할 수 있습니다.

┌──────────────────────────────┐
│ 🏛 이사했는데 주소는 어디에...  🗑│
│    3분 전 · 4개 메시지          │
├──────────────────────────────┤
│ ✚ 열이 나는데 어디로...       🗑│
│    어제 · 2개 메시지            │
└──────────────────────────────┘

   [ 대화 기록 전체 삭제 ]
```

- **탭하면 대화가 복원되고 이어서 대화할 수 있다** — 읽기 전용이 아니다
- 이어쓰면 새 기록이 아니라 기존 기록이 갱신된다
- 저장 시점: AI 답변 완료마다. 최대 40개, 넘으면 오래된 것부터
- 첫 질문이 제목, 분야 색 타일, 상대 시간

### 저장 정책

`localStorage` 에만 저장한다. **서버로 보내지 않는다.**

계획서는 "세션 내에서만 유지"였다. 기록 화면을 만들면서 기기 보관으로 바꿨고, **화면의 개인정보 문구도 같이 고쳤다** — 저장하면서 "저장하지 않는다"고 표시할 수는 없다.
